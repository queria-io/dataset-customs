# 税関 輸出入統計品目表

税関の[輸入統計品目表（実行関税率表）](https://www.customs.go.jp/tariff/index.htm)と[輸出統計品目表](https://www.customs.go.jp/yusyutu/index.htm)を、SQL で検索できるテーブルにしたデータセットです。類・項・号・統計細分（9 桁の統計番号）と、品名・統計の単位を収録しています。

品名から HS コードや統計番号を探すとき、貿易統計の 9 桁の品目に品名と上の階層を付けるときに使います。

## 出典と利用条件

税関ホームページの品目表を加工して作成しています。税関ホームページのコンテンツは公共データ利用規約（第 1.0 版）で提供されています。品目表は改正のたびに日付の版で出るので、ビルドのたびに最新の版を読みます。読んだ版の日付は `edition` 列に入ります。

## テーブル

| テーブル | 内容 | 行数（輸入 2026-10-31 版・輸出 2026-01-01 版） |
| --- | --- | ---: |
| `hs.import_item` | 輸入統計品目表。1 行が 1 コード | 16,584（統計番号 9,650） |
| `hs.export_item` | 輸出統計品目表。1 行が 1 コード | 13,664（統計番号 6,730） |

## 使い方

品名に「緑茶」を含む輸入の統計番号:

```sql
SELECT code, full_name, unit_1, unit_2
FROM customs.hs.import_item
WHERE level = 'statistical' AND full_name LIKE '%緑茶%';
```

## 収録範囲の注意

- 類・項・号・統計細分が同じ表に並びます。`level` で 1 つに絞ってから数えてください
- 関税率は収録していません
- 輸入と輸出では統計細分（下 3 桁）が違います。上 6 桁の `hs_code` は共通です
- 輸入の時期で税率が分かれる統計番号は 1 行にまとめています

